# Example UI template: `example-plant`

A complete, working pyPLCHMI UI template to copy. See [../../../UI_TEMPLATES.md](../../../UI_TEMPLATES.md).

Install it: zip this folder (the ZIP may contain the folder itself or only its files) and
upload it in *Admin → UI templates*, then **Preview** and **Activate**.

```bash
cd docs/examples/ui-templates
python -m zipfile -c example-plant.zip example-plant/
```
